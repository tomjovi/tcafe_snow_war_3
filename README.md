당신은 숙련된 HTML5 웹게임 개발자입니다. 아래 요구사항에 따라 “놈들이다”라는 이름의 웹게임을 신규로 하나만 구현하세요.

# 최종 목표
- PC와 모바일 웹 브라우저에서 바로 실행되는 오프라인 HTML5 게임을 만든다.
- 플레이어 1명이 여러 적과 눈싸움을 하며, 30초 안에 최대한 높은 점수를 획득한다.
- 이 요청에서는 게임 1개만 구현한다. 다른 게임 모드나 게임 선택 화면은 만들지 않는다.

# 기술 및 출품 제약
- 사용 기술: HTML5, CSS3, Vanilla JavaScript 또는 번들링 없이 동작 가능한 경량 프레임워크.
- 반드시 정적 파일만으로 동작해야 한다.
- 외부 CDN, 외부 API, 외부 서버 요청, 웹폰트, Google Fonts, 외부 이미지·사운드 URL을 절대 사용하지 마세요.
- 모든 JS, CSS, 이미지, 사운드, 폰트, 데이터 파일은 프로젝트 내부에 포함하고 상대경로로 참조하세요.
- ZIP 압축 시 `index.html`이 반드시 ZIP의 최상위 루트에 위치해야 한다.
- ZIP 용량은 20MB 이하를 목표로 한다.
- 이미지와 사운드는 직접 생성하거나 상업적 사용이 허용된 에셋만 사용한다.
- 가능하면 이미지·사운드 의존도를 낮추고, Canvas 기반 벡터 그래픽과 Web Audio API로 생성하는 방식을 우선 고려한다.
- 모바일 세로/가로 화면, 데스크톱 브라우저에서 모두 정상 동작해야 한다.
- 반응형 Canvas를 사용하고, 모바일 브라우저의 더블탭 줌·스크롤·텍스트 선택 등이 게임 조작을 방해하지 않게 처리한다.
- 로컬 웹서버에서 실행했을 때 콘솔 오류, 404, CORS 오류가 없어야 한다.

# 공통 게임 규격
- 게임명: 놈들이다
- 장르: 1 대 N 눈싸움 아케이드 게임
- 한 판 시간: 무조건 30초 고정
- 플레이어는 화면 맨 아래에 위치한다.
- 플레이어는 좌우로만 이동할 수 있다.
- 적은 화면 위쪽 또는 중간 영역에서 등장하며, 플레이어를 향해 눈덩이를 던진다.
- 플레이어가 적에게 눈덩이를 맞히면 +10P
- 플레이어가 적의 눈덩이에 맞으면 -10P
- 점수는 0 미만으로 내려갈 수 있어야 한다.
- 게임 종료 후 점수, 명중률, 피격 횟수, 최고 연속 명중, 획득 포인트를 표시한다.
- 게임 결과 화면에 “다시 하기” 버튼과 “난이도 설정” 버튼을 제공한다.

# 필수 변수 규칙
- 게임에서 획득한 포인트는 반드시 다음 변수명으로 저장한다:
  snow_war_point
- 이 변수는 기존 사이트와 포인트를 연동하기 위한 내부 변수명이다.
- 화면 UI에는 `snow_war_point`라는 변수명을 그대로 노출하지 않는다.
- 화면에는 “획득 포인트”, “포인트”, “점수” 등 사용자가 이해하기 쉬운 이름으로 표시한다.
- 예시:
  let snow_war_point = 0;
- 적 명중 시:
  snow_war_point += 10;
- 피격 시:
  snow_war_point -= 10;
- Perfect 달성 시 해당 공격 또는 콤보의 획득 포인트는 2배로 적용한다.
- 최종 결과 화면에는 `snow_war_point`에 저장된 최종 값을 “획득 포인트” 등의 이름으로 표시한다.
- 향후 외부 포인트 연동을 고려해, `snow_war_point`는 전역 변수 또는 게임 상태 객체의 명확한 필드로 관리한다.
- 외부 연동을 위해 필요하다면 아래와 같은 getter 또는 상태 조회 방식도 제공한다.
  - getSnowWarPoint()
  - gameState.snow_war_point
- 단, 이번 버전에서 실제 외부 API 호출이나 서버 전송은 구현하지 않는다.
- 연동을 방해하지 않도록 `snow_war_point`의 이름, 자료형(정수), 증감 규칙은 유지한다.

# Perfect 규칙
- Perfect 조건은 게임 화면에 명확하게 표시해야 한다.
- Perfect 달성 시 해당 공격 또는 해당 콤보의 획득 포인트가 2배가 된다.
- Perfect 발생 시 화면에 짧고 명확한 연출과 텍스트를 표시한다.
- 예시: “PERFECT! +20P” (일반 명중 10P의 2배)
- Perfect 조건은 너무 복잡하지 않게 하고, 플레이어가 이해할 수 있어야 한다.

# 조작 방식
플레이어 조작은 최대한 단순해야 한다.

## 이동
- PC 마우스: 화면 내 마우스 드래그로 좌우 이동
- 모바일: 화면 좌우 슬라이드로 좌우 이동
- 키보드: 왼쪽/오른쪽 화살표로 좌우 이동

## 공격
- 게임이 진행되는 동안 플레이어가 일정 간격으로 자동 공격한다.
- 기본 공격은 약 0.52초 간격이며 연사 아이템을 획득하면 발사 간격이 더 짧아진다.
- 공격 입력이나 버튼 연타 없이 이동과 회피에 집중한다.

## 자동 공격 규칙
- 눈덩이는 플레이어 위치에서 일정 간격으로 자동 발사되며 기본적으로 위쪽을 향한다.
- 연사 아이템은 자동 공격 속도를 높인다.
- 산탄 아이템이 활성화되면 자동 공격 눈덩이가 좌우로 조금씩 퍼진다.
- 키보드, 마우스, 터치 입력은 이동에만 사용하며 동시 입력 시에도 이동이 안정적이어야 한다.

# 아이템
게임 중 아래 3종 아이템을 구현한다.

1. 연사 아이템
- 일정 시간 동안 자동 공격 속도가 증가한다.

2. 큰 눈덩이 아이템
- 일정 시간 동안 자동 공격 눈덩이의 크기와 명중 판정이 커진다.

3. 산탄 아이템
- 일정 시간 동안 자동 공격 한 번에 여러 눈덩이가 나간다.
- 눈덩이는 위쪽 진행 방향을 유지하면서 좌우로 조금 퍼진다.

## 아이템 중첩 규칙
- 같은 아이템을 여러 개 먹으면 효과가 누적되어 더 강해질 수 있어야 한다.
- 예시: 연사 속도 증가, 눈덩이 크기 추가 증가, 산탄 개수 증가
- 단, 무한히 강해지지 않도록 최대 중첩 수 또는 최대 효과치를 설정한다.

## 관리자 설정
- 아이템 중첩 시 효과를 강하게 할지, 중첩을 제한할지 관리자가 설정할 수 있어야 한다.
- 난이도 설정 페이지 또는 별도 관리자 설정 화면에서 아래 항목을 조정 가능하게 만든다.
  - 아이템 중첩 허용 여부
  - 아이템 최대 중첩 수
  - 아이템 효과 배율
  - 아이템 출현 빈도
- 설정값은 localStorage에 저장하고, 게임 시작 시 반영한다.

# 난이도 설계
- 난이도는 5단계로 나눈다.
  - 1단계: 매우 쉬움
  - 2단계: 쉬움
  - 3단계: 보통
  - 4단계: 어려움
  - 5단계: 매우 어려움
- 난이도가 높을수록:
  - 적이 플레이어의 눈덩이를 더 잘 피한다.
  - 적의 이동 속도가 빨라진다.
  - 적의 공격 속도 또는 공격 빈도가 빨라진다.
  - 게임 전체 속도가 빨라진다.
- 난이도 조정 페이지를 별도로 만든다.
- 난이도 조정 페이지에서는 5단계 선택, 세부 난이도 파라미터 확인 및 수정, 기본값 복원 기능을 제공한다.
- 목표는 일반 플레이어의 성공률 또는 만족스러운 플레이 가능성이 약 60~70% 수준이 되도록 조정 가능하게 만드는 것이다.
- 난이도 파라미터는 코드에 하드코딩하지 말고 설정 객체 또는 JSON 형태로 분리한다.
- 예시 파라미터:
  - enemyMoveSpeed
  - enemyDodgeChance
  - enemyAttackInterval
  - snowballSpeed
  - itemSpawnRate
  - playerMoveSpeed
- 실제 플레이 데이터에 따라 난이도를 미세 조정할 수 있도록, 각 파라미터의 역할을 코드 주석으로 명확히 설명한다.

# 이번에 구현할 게임: 눈보라 대혼전
- 여러 적이 화면 위에서 계속 등장하고, 좌우로 이동하며 플레이어를 공격한다.
- 적은 기본적으로 좌우로 움직이며, 일정 확률로 플레이어의 눈덩이를 피한다.
- 화면에 눈보라, 바람, 눈입자 등 시각 효과를 넣어 혼전 느낌을 강조한다.
- 핵심 재미는 빠른 연사, 아이템 활용, 다수의 적을 동시에 상대하는 아케이드형 눈싸움이다.
- Perfect 조건: 같은 적에게 연속 3회 명중하면 Perfect로 처리하고, 해당 명중의 획득 포인트를 2배로 한다.
- Perfect 조건은 게임 시작 안내와 플레이 화면에 항상 표시한다.

# UI/UX 요구사항
- 게임 시작 전 타이틀 화면을 제공한다.
- 타이틀 화면에는 게임 이름, 자동 공격 규칙, 이동 조작법, 시작 버튼, 난이도 설정 버튼이 표시되어야 한다.
- 게임 시작 전에 조작법을 짧게 안내한다.
- 30초 타이머는 항상 잘 보이게 표시한다.
- 현재 점수, 획득 포인트, 남은 시간, 현재 난이도, 활성 아이템 효과를 화면에 표시한다.
- 화면 어디에도 `snow_war_point`라는 내부 변수명을 사용자에게 노출하지 않는다.
- 일시정지 화면과 결과 화면을 제공한다.
- 모바일에서도 버튼과 텍스트가 충분히 크고 읽기 쉬워야 한다.
- 색약 사용자도 구분할 수 있도록 색상만으로 정보를 전달하지 않는다.

압축을 풀고 `index.html`을 브라우저에서 열면 실행됩니다. 외부 요청 없이 동작하며, `file://` 직접 열기와 정적 웹서버 양쪽에서 사용할 수 있습니다. 소리는 타이틀 화면 우측 상단에서 켤 수 있습니다.

## ZIP 만들기

프로젝트 폴더에서 `bash build-zip.sh`를 실행합니다. Python 표준 라이브러리만 사용하는 `tools/build_zip.py`가 `dist/noemdeulida-snow-war.zip`을 만들며, `index.html`이 최상위 경로로 들어갑니다. Windows에서는 프로젝트 폴더에서 `Compress-Archive -Path index.html,css,js,config,README.md -DestinationPath noemdeulida-snow-war.zip -Force`를 실행하세요. 생성물 크기는 20MB 이하가 목표입니다.

## 차별화 요소와 게임 규칙

- Canvas로 그린 눈보라 배경, 눈송이, 눈사람 적과 충돌 파티클을 외부 이미지 없이 제공합니다.
- 모바일은 터치 시작 위치로 플레이어를 옮기지 않습니다. 손가락을 좌우로 움직인 거리만 현재 위치에 더해 스와이프 이동합니다.
- 적 처치 시 원형 충격파와 방사형 눈·얼음 파편, 섬광, 짧은 화면 흔들림이 함께 재생됩니다.
- 기본 명중은 +10P, 피격은 −10P, Perfect는 +20P입니다. 기존 브라우저 최고 점수는 새 단위에 맞춰 10배 변환합니다.
- 같은 적에게 연속 3회 명중하면 세 번째 명중이 `PERFECT! +20P`로 표시됩니다. 적마다 3회 맞으면 쓰러집니다.
- 적 명중은 점수와 획득 포인트에 +10P (Perfect는 +20P), 피격은 둘 다 −10P이며 음수 점수도 허용합니다.
- 플레이어는 자동으로 눈덩이를 던집니다. 연사는 발사 간격을 줄이고, 큰 눈덩이는 명중 판정을 키우며, 산탄은 자동 공격을 여러 방향으로 퍼뜨립니다.
- 연사 아이템은 자동 발사 간격을 줄이고, 큰 눈덩이는 크기와 명중 판정을 높이며, 산탄은 발사마다 여러 눈덩이를 퍼뜨립니다. 효과 지속시간과 중첩은 관리자 설정을 따릅니다.
- 결과는 명중률, 피격 횟수, 최고 연속 명중, 획득 포인트를 표시하고 다시 하기·난이도 설정·홈으로 이동 버튼을 제공합니다.
- 결과 화면에서 홈으로 돌아가면 타이틀 화면으로 이동하며, 진행 중인 적·투사체·효과를 정리합니다.

## 난이도와 관리자 설정

타이틀 또는 결과 화면의 **난이도 설정**에서 5단계 중 하나를 고르고 파라미터 슬라이더를 조정합니다. 적 이동 속도, 회피 확률, 공격 간격, 플레이어 눈덩이 속도와 이동 속도, 적 등장 간격, 난이도 아이템 계수를 확인할 수 있습니다. 항목 설명은 `config/difficulty.js`의 `parameterInfo`에 있습니다.

같은 화면의 아이템 설정에서 중첩 허용 여부, 최대 중첩 수, 효과 배율, 출현 빈도를 바꾸고 **저장하고 돌아가기**를 누릅니다. 값은 브라우저 `localStorage`의 `snowWar3Settings` 키에 JSON으로 저장됩니다. **기본값 복원**을 누른 뒤 저장하면 설정이 초기화됩니다.

## 포인트 내부 연동

실시간 정수 포인트는 `window.gameState.snow_war_point`에서 읽을 수 있고, `window.getSnowWarPoint()` getter도 제공합니다. 적 명중/피격 시 각각 +10/−10, PERFECT 명중은 +20이며 한 판 시작 때 0으로 초기화됩니다. 결과 화면은 이를 **획득 포인트**로 표시하고 내부 필드명은 노출하지 않습니다. 이 버전은 서버/API 전송을 하지 않습니다.

## PC·모바일 확인 목록

정적 서버를 사용할 경우 프로젝트 디렉터리에서 `python3 -m http.server 8000`을 실행한 뒤 `http://localhost:8000`으로 접속합니다. 다음 동작을 확인하세요.

- PC: 마우스 이동/드래그, 화살표 키 이동, 공격 자동 발사와 공격 위치 추적
- 모바일: 터치 시작만으로 이동하지 않는지, 좌우 스와이프 거리에 따라 현재 위치에서 이동하는지, 공격 자동 발사와 가로/세로 화면 동작을 확인
- 적을 처치해 파편·충격파·섬광·화면 흔들림을 확인
- 명중 +10P, 피격 −10P, Perfect +20P 및 결과 화면의 홈으로 버튼
- 입력을 누르지 않아도 자동 공격되는지, 연사 아이템으로 발사 간격이 단축되는지
- 기본 공격의 위쪽 진행, 산탄의 좌우 확산, 큰 눈덩이의 크기·명중 판정 증가
- 적 명중/피격 포인트, 음수 점수, 같은 적 3회 PERFECT
- 연사·큰 눈덩이·산탄의 지속시간과 관리자 중첩 상한
- 난이도 변경 저장/새로고침 복원, 기본값 복원, 30초 종료, 결과 통계와 다시 하기
- 브라우저 개발자 도구의 Console/Network에서 오류, 외부 요청, 누락 파일 여부
- ZIP을 풀어 최상위 `index.html` 포함 여부와 파일 크기를 확인
